# 0.0.2 — Capability-Based Human Smoke

This source-only release publishes commit-verifiable target runners for
AVX-512/VNNI host readiness, pinned llama.cpp `v0.7.0`, read-only external GGUF
inventory, deterministic CPU CLI/API smoke, and optional discovered NVIDIA
acceleration with reversible power limits.

AVX-512 and AVX-512 VNNI are the only universal compute requirements. Operating
system version, core count, PMem mode or size, host-memory reserve, GPU presence,
GPU model/count/architecture, and VRAM reserve are discovered facts or explicit
operator inputs—not project defaults.

The project does not acquire, convert, quarantine, promote, store, or distribute
models. Smoke requires an existing operator-provided model outside the checkout.

## Assets

GitHub-generated source archives only. No binary assets or model content.
