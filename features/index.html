Feature roadmap

  1. Repository — accepted public source and setup release.
  2. Publication — exact-SHA Pages runner closures.
  3. Target access — reversible non-root SSH enablement.
  4. Host — AVX-512/VNNI gate plus capability discovery.
  5. Models and llama.cpp — read-only external inventory and pinned side-by-side runtime.
  6. NVIDIA — optional discovered acceleration and reversible power policy.
  7. Human smoke — CPU CLI/API twice, then optional NVIDIA.
  8. 0.0.2 — reviewed source-only smoke release.
  9. 0.1.0 — KTransformers and complete MoE acceptance.

No OS version, CPU count, PMem profile, GPU model/count/architecture, or reserve value is a project default. P2P, HiCache, and Debian consumption remain deferred.
