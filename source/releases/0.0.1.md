# 0.0.1 — Standalone Repository Setup

This release establishes the standalone public repository, Apache-2.0 license,
private prompt-driven feature workflow, public roadmap, model-link-only policy,
GitHub Pages site, and source-only release process.

No runtime installer, host configuration, model inventory command, model runner,
or model file is included. All functional work remains planned for `0.1.0`.

## Assets

GitHub-generated source archives only. No binary assets or model content.
